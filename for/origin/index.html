    AndrewOS · job-search pipeline

    A job board answered 200 and served nothing.

    A company moved its board to a new token. The old one didn't 404. It returned success with an empty list.

    Every status-code check read that as "no open roles," which is a believable answer, so nothing complained. Live roles would have quietly dropped out of my pipeline.

    The fix wasn't a smarter check. I started keeping per-board counts over time and flagging any healthy board that collapses to zero on a 200. Its first run caught a second board with the exact same lie. The lesson I keep relearning: an empty success is the most dangerous answer a system can give, because it looks like an answer.

    AndrewOS · review pipeline

    Why no agent of mine grades its own homework.

    An agent asked to review its own work tends to agree with itself. That's not a trace you want to find later.

    So I made it a hard rule: no agent ever audits its own work. A reviewer runs in a separate context where it can't see the builder's reasoning, and for anything that matters I send the review to a model from a different family, because a same-family reviewer tends to nod along.

    Underneath that sits a deterministic gate that machine-checks output against written rules before anything ships. That moves correctness out of model judgment and into code, which is the same idea Veritas is built on.

    AndrewOS · scheduled agents

    Two machines, one schedule, every job twice.

    Autonomous loops run on schedules. Load the same schedule on a second machine and every job fires twice.

    For most jobs that's waste. For outreach it's a duplicate message to a real person, which is the kind of mistake that costs trust rather than compute.

    I hardened the loops against duplicate sends, double-firing schedulers and retries that weren't idempotent, and I wrote down that a second machine must never load the same automations. That's the kind of guardrail that only shows up after you've watched an agent do something you didn't expect.
