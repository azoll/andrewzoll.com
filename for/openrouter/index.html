I built the cost instrumentation because I couldn't answer the question otherwise.

AndrewOS is an agent operating system I built and run every day. The part most relevant to you is the accounting rather than the agents: usage and spend broken out by model and by workload, surfaced on a dashboard I actually look at, next to job health, queue depth and failure signals.

I built it because an agent workflow will happily cost ten times what you assumed and report nothing. There is no way to make an efficiency argument without the number, and no way to get the number by asking people.

That is the same instinct a routing product runs on. You are in the business of making a cost-and-capability tradeoff legible to someone who would otherwise guess.

Most of what I've built is an argument about where models can't be trusted.

Veritas is a citation-verification platform for legal filings. The design rule is strict: a model extracts each claim, and deterministic code renders the verdict. A fixed fixture suite gates every release. Correctness lives in code, not in model judgment.

In AndrewOS, no agent reviews its own work. A builder produces, and an independent reviewer runs in a separate context where it cannot quietly agree with itself. Under that sits a deterministic gate layer that machine-checks generated output against written rules before anything ships.

Every stage appends a trace of what it received, what it decided, and what it handed off, so a run replays as an audit record instead of a story. I learned all of that by being wrong first.
