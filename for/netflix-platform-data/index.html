AndrewOS is an agent operating system I built and run every day. It delegates work across specialized agents with human approval gates, and part of it is the instrumentation that reports what those agents actually cost, broken out by model and by workload, surfaced on a live dashboard next to job health, queue depth and failure signals.

I built the measurement layer for the same reason your team exists. You can't make an efficiency argument to engineers without usage data, and you can't get usage data by asking people.

I wanted the number, so I built the thing that produces the number.

The concern I've spent the most time on is trusting generated output. In AndrewOS no agent reviews its own work: a builder produces, and an independent reviewer runs in a separate context where it can't quietly agree with itself. Under that sits a deterministic gate layer that machine-checks generated output against written rules before anything ships, which moves correctness out of model judgment and into code.

Veritas is the strictest version. A model extracts each claim, deterministic code renders the verdict, and a fixed fixture suite gates every release.
