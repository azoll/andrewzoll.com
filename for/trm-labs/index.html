Exhibits against the req

Every line here is lifted from your job description. Filter by how honestly I clear it. Open a row to see the system behind the claim.

I built AndrewOS, an agent operating system that runs marketing, content, and operations across two of my businesses. It has a delegation hierarchy rather than one prompt: a chief of staff agent routes work to arena managers, and managers hand scoped task packets down to builder agents.

Memory is files in a version-controlled repository, not a vector blob, so every fact the agents rely on is diffable, reviewable, and attributable to a commit. That decision came from getting burned by memory I couldn't audit.

System: AndrewOS · running continuously since 2025

This is the requirement I'd want to talk about first. AndrewOS has a rule I enforce structurally: no agent audits its own work. A reviewer or validator has to run in a fresh, independent context, because an agent asked to check itself in the same context will agree with itself almost every time.

On top of that, every stage of a manager to builder to reviewer run appends a structured trace: what it received, what it decided, why, and what it handed off. Append only. A finished run reads top to bottom as a replayable record, which is the surface I review instead of raw agent output.

Irreversible actions sit behind a human gate. Agents draft outreach; they do not send it. That is a design constraint I chose before it was a preference, and it is the same shape as the governance layer your team owns.

System: AndrewOS observability layer · agent-trace spec

Veritas is a citation-verification platform for legal filings. It checks the cases and quotations in a brief against source records and returns an auditable verification record. Hallucinated citations are the entire problem it exists to catch.

The architecture is deliberate: extract the claim with the model, then decide with deterministic code. The model is good at reading a messy citation out of prose and bad at being trusted about whether it is real, so the judgment never sits with it. I hold the pipeline against a fixed fixture suite and no release ships that fails it.

I also chose the verdict language carefully. The product says a citation was not located in reporter rather than calling it false, because a lawyer acts on that sentence in a filing and the honest hedge matters more than the confident one.
