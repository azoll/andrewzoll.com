Your four projects, and where I'd start

The posting names four projects. Pick one.

Bring the whole development loop into a container

I've lived on the other side of this. At Coder I ran my builds through Coder Agents, Coder's own agent product, and peaked at 602 agent launches and 193 merged pull requests in one week. The thing that made it work wasn't the model. It was a workspace where the agent and I could both see the output and a reviewer could say no.

I'd start by sitting with one frontend team for a week and writing down every place the loop leaves the container today.

Honest note

I haven't built the virtualization layer itself, and I haven't shipped iOS or Android. I'd be learning Firecracker or gVisor on the job, and I'd lean on the mobile engineers for what "visually inspect" has to mean on a simulator.

Plug the agents into the systems people already use

At Coder I built integrations for Salesforce, Granola meeting transcripts and a Slack bot, and I shipped an OAuth authorization server that gated hosted MCP access to the platform. The work turned CRM, support and call-transcript data into answers for people who aren't engineers.

I'd start with a short list of the tools Aura's teams open every morning and a plain rule for what an agent may read and write in each.

Receipt

884 merged pull requests in Python and TypeScript on that platform between July 27 and October 9, 2026.

Find out who's actually using it

I tracked model cost per merged pull request, which came to about $38 in that peak week, and I kept a ledger of every review verdict. Across about 1,200 verdicts on about 350 pull requests, reviewers recorded more than 430 confirmed catches and 21 false flags. Numbers like those told me which tools were earning their keep.

I'd start with three questions per team: who used it this week, what did it finish, and what did it cost.

Honest note

I measured my own pipeline, not adoption across a 1,000-person company. The instrumentation is familiar. The scale isn't.

Share what keeps customer data safe

I shipped fail-closed Federal data access controls across 26 merged pull requests. The platform classified Federal accounts, withheld unproven Federal history from model input for uncleared users, and tested every access tier. For a company that protects families and schools, I'd expect data governance to matter more here, not less.

I also built Veritas, a citation-verification product for legal filings, where a wrong answer is worse than no answer. That habit carries over.

Receipt

FieldCommand, a multi-tenant SaaS I built solo on PostgreSQL and Supabase, with role-based access control and tenant isolation, and four AI features behind per-tenant feature flags.
