"Design reliability infrastructure for multi-model LLM services. Structured output validation, fallback chains, circuit breakers for external APIs, and quality controls that catch hallucination before users see it."

This is the paragraph that made me apply. Veritas exists because of the hallucination problem specifically. Lawyers were filing briefs citing cases that did not exist. The product checks every citation against source records, and its verdict language is deliberately hedged, because a confident wrong answer about a court filing is worse than no answer at all.

Across my systems, the pattern is the same: hard gates written in plain code around the places where a model being creative would be a disaster. A deterministic linter blocks anything going out under my name. A duplicate-send guard reads the live sent record and fails closed when it can't. A freeze flag halts all sending when the bounce rate crosses a threshold. Models decide what to say. Code decides whether it's allowed to leave.
